# Who win at lucky wheel

A lucky draw game that runs in any browser, on a laptop or a smartphone.

## How to play

1. The game master types the names, one per line or separated by commas, then presses **Load the wheel**.
2. Press **SPIN** in the middle of the wheel. The wheel stops on one name: the winner.
3. The winner is written in the list on the left and removed from the wheel after **Continue**.
4. Spin again as many times as you like.
5. Press **Stop** to see the full list of winners, then **Start over** for a new game.

The **Day / Night** button switches the screen theme, and **Sound** turns the effects on or off.

## Run it

Open `index.html` in a web browser. No installation needed.

To play it online, enable GitHub Pages for this repository (Settings → Pages → Deploy from branch `main`, folder `/root`).
